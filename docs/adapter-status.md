# 阶段 05 · 在线评测状态

Adapter 的 result/status 仅查询当前已登录账号、完整题目目标和（result）指定提交 ID，不携带源码、评测详情或其他账号记录。状态仅代表服务端可见记录；按数值提交 ID 选最近可见提交，AC 表示曾观察到 AC，不证明当前源码正确。分页/权限可能限制历史可见范围。

Companion 在内存中按账号与目标缓存观察证据（最多 512 项，达到上限清空），没有持久化、启动同步或周期性扫描联网。文件树只显示缓存结果，最近提交和曾 AC 分开；账号切换后不显示其他账号数据。手动刷新当前题或已展开文件树（最多 20 个唯一目标）失败时保留已有结果并显示错误。提交确认后仅轮询最新回执的已知 ID，2 秒间隔、最多约 60 秒，不重发，不自动登录；单次查询 10 秒超时，最多可有一个已开始查询越过总时限。打开设置或手动刷新时停止后续轮询；已发出的只读查询可能结束。真实平台分页和评测状态码待验收。无完整提交历史页面、无安装器修改。
