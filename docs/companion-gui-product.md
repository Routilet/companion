# Companion Next · 产品与交互设计（阶段 01）

状态：原型评审。见 [路线图](companion-next-roadmap.md)。基于当前学生流程及旧版 README、architecture、TUI、手册和测试审计。

## 产品定义

在学生已有编辑器和本地文件之上，减少代码准备、测试、资源使用、复制独立提交源码的重复劳动。不替代 IDE、文件管理器、调试器、OJ 或考试平台。普通文件无需登录、注册或初始化。考试使用由课程许可决定。

## 交互

- 初次使用仅有打开文件、打开文件夹、新建文件、手册。打开/拖入单文件自动选择父目录与该文件；打开文件夹呈现目录树；普通文件直接识别。外部增删、保存应反映，重命名关联数据策略留阶段 02。恢复上次位置。
- 新建 C 默认引入已安装 Exam Kit 的本地头文件，直接输入文件名，不询问模板/版本。C++ 使用普通模板。已有源码不改；重名不覆盖；资源缺失明确失败而非静默创建坏文件。新文件可由外部编辑器打开。
- 主界面左侧文件树，右侧当前文件工具栏及测试数据/结果。手册可在没有当前文件时独立使用；设置少量必要项。没有课程树、统计或题面页面。
- 测试数据可新增、编辑、删除，输入允许为空；“比较预期输出”显式勾选（区分无预期与空字符串）。支持运行当前/全部，取消在途操作；成功/差异/编译失败/运行失败/超时各有文字状态。失败样例直接观察。比较区显示预期和实际，差异不只靠颜色。源码或用例变化标记旧结果过期。
- 复制提交源码：有 Exam Kit 时按需展开；普通文件原样复制。测试与复制使用相同装配规则；修改后复制需提醒未验证。编译诊断定位原始源码。Observer 缺失时说明，不阻碍本地功能。
- 手册搜索名称/中文用途，分类、示例复制，当前文件应匹配其资源版本；没有文件时用已安装资源。
- 设置：编译器、编辑器；默认已有系统工具链。应用安装更新属于 Routilet。新版本保留必要非交互 CLI，具体命令阶段 02 决定。

## 功能差异

保留本地评测、字符差异、源码展开、手册、Observer 协作；去掉课程/题目绑定前置条件、两套 TUI、资源升级管理菜单、旧工作区专用操作。题面及 OJ 登录/导入/提交未来作为可选 OJ 扩展议题，不在本轮。旧发行仍支持原功能。旧数据不擅自迁移，底层安全和正确性机制不能因界面精简而删除。

## 原型

[独立 HTML](../prototypes/companion-next/index.html)，无需依赖，直接打开。全部数据模拟，既不读写真实文件、编译、联网，也不启动应用。复制仅复制明确标注的演示数据；关闭页面不保存。通过“演示场景”选择失败状态、模拟外部新增/保存；打开文件/文件夹为模拟选择，不是系统文件对话框。资源头路径和手册条目均为示意，非最终规范。界面采用系统字体、深浅色、原生 HTML 控件；键盘 Tab、Enter、Escape 和 Ctrl/⌘+O、Ctrl/⌘+Enter；未制定公共组件库。

## 待评审

文件树是否默认只显示源文件；新建文件后是否自动打开编辑器；测试区默认展示当前样例还是全部；预期比较规则及空白字符策略；手册抽屉还是独立窗口；必要 CLI 范围。存储位置、重命名、编译诊断、快照及跨应用协议留阶段 02，原型不承诺实际实现。审核前不得开始正式后端。
