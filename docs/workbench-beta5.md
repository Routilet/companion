# Companion beta.5：OJ 工作台

## 边界

文件视图仍基于物理目录和源文件，普通复制预览不触发在线提交。OJ 视图只在 Adapter 可用时出现，扫描当前根目录的本地绑定（有界），不联网；选题调用同一套本地测试与编辑器能力。设置管理账号和组件，OJ 工作台集中导入、刷新、关联、原题、提交和评测。切回文件视图后隐藏在线入口。题面为本地文档能力，不依赖 Adapter。

## 存储与导入

新 Adapter 的 import_document 方法提供题面。选择工作区内目标目录后，比赛生成 contest-<ID>/<题序>/<题序>.c 和 problem.md，单题生成独立目录。选定目录中的同题旧平铺布局保留，只补缺失或空的样例与缺失文档。已有非空样例、源码、用户文档不覆盖；不同绑定或路径冲突跳过；不自动迁移。题面保留 Markdown 原文与来源；可纳入私有 Git 仓库。图片不加载，只在阅读时显示占位；HTML 不执行，链接不导航。KaTeX 本地资源，禁用 trust。无图片下载、缓存、数据库、前端框架或 Node 运行环境。已有样例及绑定路径继续按源文件名保存。

## 评测

近期比赛只读取首页并按开始时间倒序选取最多 10 条；手动链接保留。整场刷新以比赛为单位调用 contest_status，旧 Adapter 或题库保留有界逐题查询。评测详情识别每行结果、得分表达式、时间与内存，无法识别则原文展示。反馈说明不推断具体代码错误；历史 AC 与最新结果分开。提交仍须显式核对目标、语言和源码。

## 验收

两平台实际安装和管理器调用、离线样例解析、旧绑定修复、目录安全、题面不覆盖、无 Adapter 本地功能、视图隔离、详情回退、提交确认。真实 OJ 不进行自动登录或测试提交。原始 HAR 不入仓库。
