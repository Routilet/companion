# 阶段 03 · 导入与绑定

文件夹菜单「导入 OJ 题目」，只在显式 Adapter 开发预览路径可用时出现；须先登录。粘贴单题或比赛链接、选择 C/C++、可选单题关联当前文件；预览名称、保存位置、样例数及警告后确认。默认平铺当前文件目录（无选中文件时浏览根）；比赛 A.c/B.c，单题 problem-ID.c；C 新建复用 Exam Kit，C++ 复用普通模板。冲突逐题跳过；新建路径必须无孤立样例/绑定；已有源文件仅显式单题关联，保留全部既有样例（包括空列表），无样例文档才导入公开样例。预览不写磁盘，执行前复核目录、账号、本地文件/样例版本。单题失败报告，已创建文件/样例保留，批量不是事务。不保存完整题面。

绑定 `.companion/bindings/<filename>.json` schema 1；含 adapter、target、title、label、sourceUrl，不含账号或完整题面。绑定以路径为键；应用内重命名移转绑定及既有样例，新建检查孤立绑定；外部重命名不猜测；外部删除保留绑定，重新创建路径可能出现旧关联，必须人工核对、解除后再导入；尚无独立孤立绑定恢复界面。原题链接由严格校验的目标生成（比赛链接打开整个比赛）；即使 Adapter 不可用也可读取绑定和打开原链接、解除绑定，不影响本地样例或源码。重新导入不会覆盖绑定或样例；暂不做专门样例刷新/合并界面。未开放提交或在线评测。

本地 Go 1.23.2：隔离宿主 race/vet、导入模拟会话、冲突、样例修订、路径链接拒绝、绑定保存/迁移/删除测试通过；Windows amd64、macOS arm64 CGO=0 测试二进制交叉编译通过；独立 TypeScript strict 检查通过。完整 Wails 构建、真实安装发现、平台访问和真机操作依赖后续验收。专项 CI 固定 Adapter 阶段 03 提交。
