# Companion 0.1.0

首个正式发行版本。通过 Routilet 0.1.8 或兼容新版的正式通道安装；Windows 11 x64 / Apple Silicon macOS 12+。可选 Accoding Adapter 0.1.0、独立 Exam Kit 0.6.10 与 Observer。

- 文件优先的 C/C++ 工作区、外部编辑器、样例自动保存、本地测试与逐行输出对比。
- 紧凑 OJ 比赛选择与题号矩阵、当前题目定位、单一源码操作菜单、统一输出区。
- 近期比赛优先导入；链接备用；预览确认和不确定进度提示，保留现有源码及样例。
- 显式确认在线提交、评测详情与未决核对，离线功能不依赖 OJ。
- Exam Kit 版本化快照、按需展开和离线手册；Observer 独立观察。
- 不自动迁移旧课程目录、不自动升级历史资源、不引入运行时 AI。

正式发布门禁为前端浏览器回归、Windows/macOS 原生构建、候选包安装与 Adapter 宿主联调，并核对 npm 依赖可见性。自动化不执行真实 OJ 提交；最终原生窗口仍以用户安装后的实际体验为准。macOS ad-hoc 签名，未公证。
