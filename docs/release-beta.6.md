# Companion 0.1.0-beta.6

- 测试优先工作区：样例与结果统一、默认运行全部、样例自动保存与冲突保护；状态即详情入口，紧凑比赛选择与题号矩阵。
- 有意义的比赛目录命名，旧布局及用户命名保留；重复导入按本地绑定复用。
- 设置仅偏好和组件状态；OJ 账号入口独立，进入 OJ 时一次恢复保存的登录，未登录可继续本地测试。在线提交自动只读核验，最终确认不可省略。
- Exam Kit 按需读取，无需重启 Companion；新建采用当前已安装版本，旧代码仍引用历史快照。当前源码、普通目录及比赛菜单提供同一切换窗口。默认只选与初始模板完全一致的旧资源源码；其他文件需显式选择。先保存并关闭外部编辑器的受影响文件，切换重新校验摘要及资源版本。保留旧快照，不自动升级或删除。普通 C 接入须显式选择；不支持复杂、歧义或损坏引用。
- 配套 Routilet 0.1.8 修复 GUI 启动资源锁竞争。

测试版本 next，真实账号和原生窗口的日常体验仍需用户实测；自动化不进行真实 OJ 提交。参见 [产品原则](product.md)。
