# 产品定义：降低编程练习与验证成本

状态：beta.5 后的交互收敛规范，待维护者真机验收；不改变发行版本。

Companion 是面向 C/C++ 课程的本地源码辅助工具，不是编辑器、IDE 或 Accoding 桌面复刻版。以普通文件为基础，减少选择样例、编译、运行、比较、修改、重跑与提交的操作成本。OJ、Observer、Exam Kit 独立可选；不生成解题代码，遵守考试规定。

## 原则

- 源码是操作对象，测试是主体，题面和评测是上下文。单一稳定的测试工作区；文件和 OJ 仅是两种导航投影，不是两套测试界面。
- 尽可能少的操作获得尽可能多的有效信息。入口唯一、直接操作、状态就地表达、信息按需出现。能由对齐、空间、状态标记准确表达的语义不重复常驻文字；已实现不是保留功能的理由，无独立价值的入口及逻辑删除。
- 样例输入、预期与实际输出属于同一对象。预期只展示一次；差异直接在输出区呈现。无预期、空预期、未运行、异常、过期、截断和比较规则须可辨，不以颜色为唯一表达；不把旧结果冒充当前结果。
- 默认运行全部样例，单组运行按需；运行状态在操作位置体现。用户数据自动保存须有 revision 冲突保护、失败可见、切换前落盘；不因简化覆盖或丢弃用户修改。
- 题面由题目标题进入，在线评测由状态进入，手册由全局唯一入口进入；长文与完整诊断按需阅读，不挤占测试主体。外部编辑器保留直接入口。
- OJ 比赛选择器与紧凑题号导航优先；题号与历史 AC、最新结果、未查询状态区分，标题和完整路径按需可见。普通文件保持物理目录语义；目录名称不是远程身份。
- 提交前自动只读核验，最终明确确认账号、题目、语言和源码；未知语言不可猜测，未决提交不得自动重发。普通源码复制不依赖 OJ。缩减交互不缩减安全校验。
- 不创建通用 GUI 插件框架、公共组件库或新数据库；本地文件功能不启动 OJ 网络操作。采用系统字体、深浅色、高对比度、键盘可达与稳定布局。无装饰性动效。

## 基本工作流

选择源码 → 外部编辑 → 运行全部 → 查看当前样例的真实差异 → 修改与重跑 → 复制或显式确认在线提交。题面、手册、Observer 按需使用。导入生成可复习的本地 Markdown 与源码，保留已有关联、用户命名、非空样例和文档，不强制迁移。

## 本轮范围与后续

主区、样例输出、导航、入口与提交流程精简；Exam Kit 启动锁冲突的有限重试是故障修复，不是更新策略变更。设置页面、登录提示及自动恢复的具体交互、Exam Kit 更新/快照升级策略留给维护者下一轮讨论，不先冻结。未完成项目在 PR 明列，不宣称全部验收。

## 验收

以普通 C 文件、已有平铺导入、新一题一目录及 51 题比赛验证：运行前后布局稳定，预期不重复，差异和旧结果可辨，键盘操作可达，保存冲突不丢数据，未安装 Adapter 仍可运行和阅读；提交确认与未决保护不变。Windows 11 amd64 / macOS arm64 构建、实际安装、浏览器回归与维护者原生窗口验收分开。参考 [Observer 产品定义](https://github.com/Routilet/c-observer/blob/main/docs/product.md) 和 [设计](https://github.com/Routilet/c-observer/blob/main/docs/design.md)。

## 导入命名
新比赛默认使用跨平台安全化后的标题，可在预览修改名称，重算本地计划而不重复请求 OJ。既有绑定匹配的平铺、旧 contest-ID 或改名目录优先复用；多个副本要求选定具体目录，不自动合并、重命名或覆盖。当前范围为选定导入位置及其直接比赛子目录。
