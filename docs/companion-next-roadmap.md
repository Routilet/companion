# Companion Next · 重构路线图

2026-11-27 · 阶段 00/01 待维护者评审。依据组织级共同决策修订 PR [Routilet/.github#1](https://github.com/Routilet/.github/pull/1)。不是发布时间承诺。

## 产品基线

面向 C/C++ 学习者的本地编程辅助工具；普通文件是主体，零初始化、离线、非侵入。打开单文件自动打开其父目录并选中；新建 C 文件默认引用本地 Exam Kit 头文件。外部编辑器写代码；Companion 负责测试、参考资源、独立提交源码；Observer 仍独立可选。平时 OJ、考试另一离线平台；本轮不做 OJ 插件或通用插件系统。课程实际许可决定考试可用功能。

目标 Go + Wails v3 + TypeScript Web 前端，Windows 11 amd64、macOS arm64；沿用组织的系统 WebView、预构建与签名策略。旧 TS 发行维持，旧代码/测试作为行为参考，不逐行翻译，不更改正式包或用户数据。

| 07 验收迁移 | 双平台真机、用户数据保护、旧版迁移方案 | 用户确认后另议发行；CI 不代替真机 |

阶段 01 通过前不开发 02–07。阶段 05/06 依赖外部协议，前面阶段不阻塞 Observer 或 Routilet 开发。旧版 OJ 逻辑与凭据保护经验完整保留供未来独立扩展；不实现接口、加载器、扩展管理。Exam Kit 现有格式优先，不要求同步重构。

## 验收底线

新手可拖入普通 C 文件、粘贴样例并完成第一次测试；文件夹无需注册。外部新增/保存可感知。没有预期输出时仅运行，明确空输出可判定。源文件/资源/测试变化不能误用旧通过结果。错误区分编译、运行、超时和输出差异。测试/复制不覆盖用户文件；资源留在用户目录，卸载不破坏代码。已有工作区兼容与迁移单独审核。没有 Observer 仍可正常测试。考试期间不自动联网或下载。真实编译器由用户已有环境提供，不承诺沙箱。

## 分支与审核

本 PR 仅新增文档和独立原型。后续阶段独立 PR、明确基线与范围，未经确认不合并、不发布、不归档旧代码、不更改仓库/npm 名。原 Node 实验分支如存在仅保留记录，不再推进。
