# 阶段 04 · 在线提交闭环

复用原有源码预览（PrepareSubmission/CheckSubmission）；普通文件、Adapter 缺失或离线时仍可复制。绑定文件可主动核验远程目标，然后明确选择平台实际返回的语言并核对账号、题目与预览源码。预览未完整通过本地测试不禁止提交，沿用警告。发送时再次检查磁盘源码、资源、样例、编译配置、题目绑定、账号及预览对象，消耗一次性确认，并只传已确认的原始 UTF-8 文本；不从前端接受源码，不自动切换目标。Adapter 再次核验平台身份、题目和语言，并在发送 POST 前持久化尝试记录。

当前仅展示已确认的提交 ID 与首次回执状态；不是历史 AC 状态或当前源码正确性的证明。网络或 IPC 断开时明确提示不确定，禁止透明重试。用户主动“核对未决提交”只读访问平台；唯一匹配的题库提交可确认；比赛或未唯一匹配的记录保留保护，不能自动解锁。残留锁、比赛核对需维护者协助。正式安装发现、真实账号及真机验收、文件树 AC、持续轮询和远程状态缓存仍待后续。具体存储与恢复约束见 Adapter docs/submit-v1.md。

Linux 隔离宿主测试（含真实 Adapter 二进制握手、模拟预览/发送/断线/重复令牌）、race、vet、Windows amd64/macOS arm64 非 CGO 测试二进制交叉编译及独立 TypeScript strict 通过。完整桌面层新增测试及实际 Wails 构建交由双平台 CI；不进行真实平台提交。
