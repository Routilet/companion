# Companion 交互体验优化

基线：beta.2 main。独立分支开发，未授权合并或发布。保持文件优先、显式保存、现有资源快照与样例语义。Adapter 账号和协议不在范围内。

1. 新建：根目录默认、上下文目录、可选外部目录、空工作区；取消无导航副作用。新建成功才切换根目录；不覆盖。
2. 编辑器：工作区直接选择，有限范围离线检测，明确系统默认选项，自定义可执行路径；保留既有配置。
3. 文件树与手册目录：紧凑统一、稳定更新、定位、折叠、自然排序。
4. 手册：保留版本绑定，改善目录/搜索/排版、阅读状态、示例与接口复制；不改资源格式。
5. CSS 微交互、reduced-motion，双平台 CI 和真实 WebView 验收。

暂缓多窗口、拖动移动源码、收藏、公共组件库与 Exam Kit 分类结构修改。自动检测并不覆盖所有安装方式；自定义路径作为回退。真机确认编辑器启动及系统对话框。

## 本轮范围细化
- 自动检测使用 PATH 和有限常见安装路径；不遍历磁盘、不依赖网络。未覆盖的编辑器手动选择；注册表及更多安装方式可后续补充。
- 文件树保留路径键节点和最近根目录的展开状态（UI 本地存储），不移动源码和样例。
- 分类索引由当前版本目录及条目生成；不改写资源分类层级。手册恢复按资源指纹区分，仅应用会话内；不跨版本复用内容。函数签名复制重新验证版本和条目。
- 暂不添加手册结构化参数元数据（需 Exam Kit 更新）；保留现有说明。动画仅颜色、箭头、菜单、对话框，长列表及测试结果立即呈现。
- 验收：前端模拟 Wails RPC 回归、Go 核心和 Windows/macOS 原生构建；真机编辑器检测和原生对话框仍须人工验证。
