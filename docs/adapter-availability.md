# Adapter 可用性与界面修正

真实设备报告旧版把检查失败统一显示为未安装、禁用或校验失败；尚无用户本机错误详情，不能断言根因。离线管理器检查限时增加至 10 秒，区分锁冲突、超时、无法启动、未安装、禁用、清单、哈希、文件路径及未知错误；仅对明确锁冲突短暂重试。只使用白名单诊断，不显示原始 stderr 或文件路径，不绕过校验、不联网、不自动安装。设置页提供重新检查。

未通过检查时隐藏文件夹导入/刷新、绑定和解除关联/原题、树评测标记、当前题刷新、提交区域；保留普通复制和本地功能。已有绑定及样例不删除，重新检查可恢复显示。主动检查失败时关闭旧会话，不删除系统凭据；运行期间不做后台联网检查。开发测试覆盖分类、隐藏与恢复。真实设备原因仍需新版诊断复核。
