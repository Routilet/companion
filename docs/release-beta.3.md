# Companion 0.1.0-beta.3 测试版

- 工作区：根目录默认新建、选择外部目录、创建文件夹、定位及折叠；按路径更新文件树节点，保留展开状态；编辑器自动检测与显式选择。
- 离线手册：分类目录、搜索、签名与示例复制、轻量高亮；保留单窗口。
- 可选 Accoding：独立账号会话及系统凭据、只读题目/比赛导入、样例及绑定保护、源码预览和显式语言确认、未决记录防重发、评测查询与历史 AC 区分。
- 正式 Routilet 接入：使用注入管理器入口与受保护 stdio；无 Adapter 时本地功能不受影响。

## 安装

Routilet 0.1.6，测试通道，安装/更新 Companion；需要在线功能时独立安装 Accoding Adapter 0.1.0-beta.1。Exam Kit 0.6.10 自动作为固定资源依赖安装，Observer 不强制安装。支持 Windows 11 x64、Apple Silicon macOS 12+。
